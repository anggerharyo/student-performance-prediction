## Student Academic Performance Prediction 
A machine learning project to predict student academic performance using academic, behavioral, socioeconomic, and parental factors. This project applies feature engineering, regression modeling, hyperparameter tuning, and explainable AI to identify the factors associated with students' academic performance.

```
This project was developed as part of my undergraduate thesis through a publication-based pathway and resulted in a research paper published in a SINTA 3-indexed journal.
```

### Overview
The project applies machine learning regression techniques to predict student academic performance and identify the factors that contribute most to the prediction.

The workflow includes:
```
- Data preprocessing & exploratory data analysis
- Feature engineering
- Regression model comparison
- Hyperparameter tuning
- Model evaluation
- Explainable AI using SHAP and PDP
```

### Models
Seven regression algorithms were evaluated:
```
- Linear Regression
- Ridge
- Lasso
- Elastic Net
- Random Forest
- XGBoost
- LightGBM
```
Three additional features were created through feature engineering:
```
- Study_Efficiency
- Socioeconomic_Index
- Parental_Support_Index
```
The model was further interpreted using SHAP and Partial Dependence Plots (PDP) to understand feature contributions and prediction patterns.
